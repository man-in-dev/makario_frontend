1. Copy this template for each city

3. Replace `[HINDI]` with city name in Hindi
4. Update keywords with city-specific terms
5. Adjust content with local information
6. Create page at `/[city-slug]`

## Content Tips for City Pages

### Localization Tips
- Use local area names/landmarks
- Mention local weather (winter heating, summer cooling)
- Reference local festivals
- Include local delivery partners if applicable
- Use local examples in recipes/benefits

### SEO Tips
- Unique content for each city (not duplicate)
- Local keywords in H2, H3 tags
- City name in first 100 words
- Internal links to state page and main shop
- Link to blog posts about makhana

### Conversion Tips
- Simple CTA buttons
- Show local delivery times
- Display [CITY] customer reviews prominently
- Mention current offers/discounts
- Make ordering process 1-click

## Implementation Steps

1. **Create Page Template** (Component)
   - Make reusable React component
   - Pass `cityName`, `cityCode`, `cityKeywords` as props
   - Keep content modular

2. **Create City Data** (JSON)
   ```json
   {
     "delhi": {
       "name": "Delhi",
       "hindi": "दिल्ली",
       "keywords": ["मखाना दिल्ली", "..."],
       "areas": ["North Delhi", "South Delhi", "..."],
       "deliveryTime": "Same day",
       "image": "/delhi-image.jpg"
     }
   }
   ```

3. **Generate Pages Programmatically**
   - Loop through cities
   - Generate dynamic routes
   - Auto-generate XML sitemap

4. **Test & Optimize**
   - Check each page loads properly
   - Verify keywords are visible
   - Test CTAs work
   - Monitor Google Search Console
